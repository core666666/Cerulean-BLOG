# Cerulean Blog Java项目功能拆解分析

## 项目概述

**项目名称**: Iceberg Blog (Cerulean Blog)  
**技术栈**: Spring Boot 2.1.0 + MyBatis + Thymeleaf + MySQL  
**包结构**: `com.site.blog.my.core`

---

## 一、项目整体架构

### 1.1 分层架构
```
Controller层 (前端控制器)
    ↓
Service层 (业务逻辑层)
    ↓
DAO/Mapper层 (数据访问层)
    ↓
Entity层 (实体模型层)
```

### 1.2 核心包结构
- `controller/` - 控制器层
  - `admin/` - 后台管理控制器
  - `blog/` - 博客前台控制器
- `service/` - 业务逻辑接口
  - `impl/` - 业务逻辑实现
- `dao/` - 数据访问接口(Mapper)
- `entity/` - 实体类
- `config/` - 配置类
- `interceptor/` - 拦截器
- `util/` - 工具类

## 二、数据库模型分析

### 2.1 核心实体表

#### tb_admin_user (管理员用户表)
```java
- adminUserId: Integer (主键)
- loginUserName: String (登录用户名)
- loginPassword: String (登录密码, MD5加密)
- nickName: String (昵称)
- locked: Byte (是否锁定)
```

#### tb_blog (博客文章表)
```java
- blogId: Long (主键)
- blogTitle: String (标题)
- blogSubUrl: String (自定义路径)
- blogCoverImage: String (封面图)
- blogCategoryId: Integer (分类ID)
- blogCategoryName: String (分类名称)
- blogTags: String (标签, 逗号分隔)
- blogStatus: Byte (状态: 0草稿/1发布)
- blogIsTop: Byte (是否置顶: 0否/1是)
- blogViews: Long (浏览量)
- enableComment: Byte (是否允许评论)
- isDeleted: Byte (软删除)
- createTime: Date (创建时间)
- updateTime: Date (更新时间)
- blogContent: String (文章内容, Markdown格式)
```

#### tb_blog_category (分类表)
```java
- categoryId: Integer (主键)
- categoryName: String (分类名称)
- categoryIcon: String (分类图标)
- categoryRank: Integer (排序值)
- isDeleted: Byte (软删除)
- createTime: Date (创建时间)
```

#### tb_blog_tag (标签表)
```java
- tagId: Integer (主键)
- tagName: String (标签名称)
- isDeleted: Byte (软删除)
- createTime: Date (创建时间)
```

#### tb_blog_tag_relation (博客标签关联表)
```java
- relationId: Long (主键)
- blogId: Long (博客ID)
- tagId: Integer (标签ID)
- createTime: Date (创建时间)
```

#### tb_blog_comment (评论表)
```java
- commentId: Long (主键)
- blogId: Long (博客ID)
- commentator: String (评论者名称)
- email: String (评论者邮箱)
- websiteUrl: String (评论者网站)
- commentBody: String (评论内容)
- commentCreateTime: Date (评论时间)
- commentatorIp: String (评论者IP)
- replyBody: String (回复内容)
- replyCreateTime: Date (回复时间)
- commentStatus: Byte (状态: 0待审核/1已审核)
- isDeleted: Byte (软删除)
```

#### tb_link (友情链接表)
```java
- linkId: Integer (主键)
- linkType: Byte (类型: 0友链/1推荐)
- linkName: String (链接名称)
- linkUrl: String (链接地址)
- linkDescription: String (链接描述)
- linkRank: Integer (排序值)
- isDeleted: Byte (软删除)
- createTime: Date (创建时间)
```

#### tb_config (配置表)
```java
- configName: String (配置项key)
- configValue: String (配置项value)
- createTime: Date (创建时间)
- updateTime: Date (更新时间)
```

## 三、功能模块详细拆解

### 3.1 前台博客功能模块

#### 3.1.1 首页展示
**Controller**: `MyBlogController`  
**接口路径**:
- `GET /` - 首页
- `GET /index` - 首页
- `GET /index.html` - 首页
- `GET /page/{pageNum}` - 分页浏览

**功能描述**:
- 显示博客文章列表(分页)
- 显示最新文章列表
- 显示热门文章列表(按浏览量)
- 显示热门标签云
- 显示网站配置信息

**Service依赖**:
- `BlogService.getBlogsForIndexPage()` - 获取首页文章分页
- `BlogService.getBlogListForIndexPage(type)` - 获取侧边栏文章列表
- `TagService.getBlogTagCountForIndex()` - 获取标签统计
- `ConfigService.getAllConfigs()` - 获取配置

#### 3.1.2 文章详情页
**接口路径**:
- `GET /blog/{blogId}` - 按ID访问
- `GET /article/{blogId}` - 按ID访问(别名)
- `GET /{subUrl}` - 自定义URL访问

**功能描述**:
- 显示文章详细内容
- Markdown转HTML渲染
- 文章浏览量+1
- 显示评论列表(分页)
- 评论功能(带验证码)

**Service依赖**:
- `BlogService.getBlogDetail(blogId)` - 获取文章详情
- `BlogService.getBlogDetailBySubUrl(subUrl)` - 按自定义URL获取
- `CommentService.getCommentPageByBlogIdAndPageNum()` - 获取评论分页

#### 3.1.3 分类/标签页
**接口路径**:
- `GET /category/{categoryName}` - 分类文章列表
- `GET /tag/{tagName}` - 标签文章列表

**功能描述**:
- 按分类筛选文章
- 按标签筛选文章
- 分页展示结果

**Service依赖**:
- `CategoryService` - 分类服务
- `TagService` - 标签服务
- `BlogService.getBlogsPageByTag()` - 按标签获取文章

#### 3.1.4 搜索功能
**接口路径**:
- `GET /search/{keyword}` - 关键词搜索

**功能描述**:
- 全文搜索文章
- 搜索结果分页
- 关键词高亮

**Service依赖**:
- `BlogService.getBlogsPageBySearch()` - 搜索文章

#### 3.1.5 友情链接页
**接口路径**:
- `GET /link` - 友链页面

**功能描述**:
- 显示友情链接
- 按类型分组(友链/推荐)

**Service依赖**:
- `LinkService.getLinksForLinkPage()` - 获取链接列表

#### 3.1.6 评论功能
**接口路径**:
- `POST /blog/comment` - 提交评论

**功能描述**:
- 验证码验证
- 评论内容验证
- IP记录
- 评论状态(待审核)

**Service依赖**:
- `CommentService.addComment()` - 添加评论
